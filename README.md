No projeto optei por utilizar Android Jetpack Compose porque ele torna o desenvolvimento de interfaces muito mais rápido, moderno e flexível. 
Além de reduzir a quantidade de código em comparação ao XML tradicional, o Compose facilita a manutenção e evolução do app, já que a UI é escrita de forma declarativa
e integrada ao Kotlin. Essa escolha acabda trazendo mais produtividade no desenvolvimento e resulta em uma interface mais fluida e intuitiva para os usuários.
